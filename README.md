# Инди · Солнечный храм · Компьютер

[Играть](https://vasio.github.io/indi-desktop/)

Версия 0.3.0. Шесть глав: джунгли, пещера, гора, храм, подводный ход и каменный голем. После солнечного пьедестала — семь секунд побега, прыжок в водопад и река к Джине и лодке.

← → — движение; ↑ — прыжок/подъём; ↓ — взаимодействие/спуск; пробел — кнут.

Все ресурсы встроены в автономный `index.html`. Сохранения этой платформы остаются в браузере.

Единые исходники компьютерной и мобильной игры поддерживаются в каноническом проекте `indi-adventure`. Движок Phaser 4.2.1 распространяется по MIT: [лицензия и авторство](PHASER-LICENSE.md).
