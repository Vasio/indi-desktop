# Инди · Солнечный храм

[Играть на компьютере](https://vasio.github.io/indi-desktop/)

Шесть глав пиксельного приключения: джунгли, пещера, гора, древний храм, подводный ход и Хранитель-паук.

Управление: ← → — движение, ↑ — прыжок, ↓ — взаимодействие и спуск, пробел — кнут. Прогресс сохраняется в браузере.

Игра полностью содержится в `index.html`: её можно скачать и открыть без интернета.
